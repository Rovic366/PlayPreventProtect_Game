# Play, Prevent, Protect 🛡️

> ## ⚠️ Disclaimer
> *Play, Prevent, Protect* is an educational game made for a thesis at Bulacan State University – Meneses Campus. All characters, companies, and numbers in this game are made up. Any resemblance to real people or companies is a coincidence. 
>
> This is only a simulation. No real money or accounts are involved, and the game will not ask for your real personal information. The scams shown are based on common fraud tactics so you can learn to spot them. This is not legal or financial advice.
> 
> **Were you scammed in real life? Call 1326, the government's anti-scam hotline.**

**Play, Prevent, Protect** is an interactive, educational mobile game designed to help players identify different types of fraud and real-world scam scenarios. By navigating through various situations, players learn how to protect themselves and make safe decisions.

## 📱 Supported Platforms
* **Android Only** (.apk)

## ⚙️ Installation Instructions

Because this game is not distributed through the Google Play Store, you will need to allow your device to install the APK directly:

1. Download the `PlayPreventProtect.apk` file to your Android device.
2. Open your device **Settings** and navigate to **Security** (or **Apps** depending on your device).
3. Enable **Install from Unknown Sources** (or "Allow apps from this source" for your web browser/file manager).
4. Locate the downloaded `.apk` file in your Downloads folder and tap it to **Install**.
5. Once installed, tap **Open** to start the game!

## 🎮 How to Play

* **Screen Orientation:** Please ensure your device is rotated to **Landscape mode** before starting for the best visual experience and proper UI scaling.
* **Safe Tapping (Important):** To avoid accidentally choosing an option the moment a choice appears on screen, **only tap on the left and right sides of the screen** to advance text or explore. Avoid tapping the center of the screen.
* **Exploration:** Tap to interact with objects in the environment (such as mobile phones) to trigger events and continue the scene.
* **Decision Making:** Throughout the scenarios, you will be presented with multiple choices. Read carefully and select the best response to progress through the story and learn how to handle fraudulent situations.
* **Scoring System:** Be careful with your answers! The game tracks your choices and calculates a final score at the end. If you fail to get the right score, don't worry—you can always retry the scenarios to learn from your mistakes and improve.

## 🛠️ Built With

This game was developed and compiled using the following technologies:

* **[GDevelop](https://gdevelop.io/):** The core game was created using GDevelop, an open-source, cross-platform 2D game engine. GDevelop uses an intuitive, event-driven programming system that allows developers to build complex logic and engaging interactive scenes efficiently.
* **[Apache Cordova](https://cordova.apache.org/):** The web-based game files were compiled into a native Android APK using the Cordova Command Line Interface (CLI), allowing the game to run smoothly on mobile devices.
